> **Mandatory:** Read `AGENTS.md`, `docs/05_PHASE_PLAN.md`, `docs/06_QA_ACCEPTANCE.md` and `progress/phase_status.json` first. Do not start unless the prior phase is explicitly approved, except P00.

## Task

**Precondition:** P03 approved. Create small Unity 6 WebGL-ready 3D sorting-room vertical slice with real approved pilot car/package, 10–30 instances (repeated pilot instances allowed only as temporary stress/test representations, labeled as placeholders), a pile, simple table, 3–4 shelf slots, pick up/drag/snap, collection counter, simple inspect view and save/reload.

Use actual Blender exports. The Card shows exact UV texture. Blender-rendered images are NOT acceptable evidence of Unity. Create a real Unity scene and browser build; test 1 inspection car at high detail, pile objects with cheap colliders and shelf cards with flat thumbnails. Profile browser loading and frame rate where tools permit. Create `production/QA/P04/browser_results.md`, screenshots/recorded builds, and remaining issues. The game must support open-ended room progression, not numbered levels. STOP for human P04 approval.
