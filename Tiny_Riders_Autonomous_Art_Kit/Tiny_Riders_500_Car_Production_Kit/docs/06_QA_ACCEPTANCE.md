# Autonomous art QA (not manual approval)

Record artifacts and inspect actual renders. Never call unfinished catalog records finished models. Every `AUTO_QA_PASS` needs filenames and real evidence.

1. **Reference/style**: ten boards actually viewed; one shared intentionally chunky toy language; 50 base silhouettes visually distinct in contact sheets. No failed realistic wedge or unrelated generic four-door clones.
2. **Geometry**: wheels aligned and grounded; no unintended penetrations; thick valid accessories and custom physical changes; consistent axes/scales; no invisible empty car meshes.
3. **Texture separation**: print is UV-mapped 2D; no Blender text converted to meshes, modeled logos, fake shader highlights as geometry; gray-clay render removes all print.
4. **UV artwork**: crisp letters/numbers not mirrored on any side; every material maps to a real saved source image; no stretched racing stripes.
5. **Packaging**: 120x180 mm, exact shared logo, die-cut, 1200x1800 px front/back source; same master layout for all 500, family only changes thematic skin; actual printed car render matches physical model/livery/parts; no duplicate car illustration behind blister.
6. **Catalog**: exactly 50 base IDs, 100 physically different build definitions and 500 final SKUs from existing catalog; no duplicates or gaps; each SKU has actual art outputs.
7. **Environment**: actual room shell, shelves, sorting table, display/pile container, cabinets, signs, cartons, sample scenes; text/logo on texture only.
8. **Unity import**: only art prefabs/scenes and supporting importer code, no gameplay. Actual FBX/material/texture and Unity screenshot evidence when Unity accessible; otherwise marked Unity unverified.
9. **Resumable**: automatic log/checkpoint after each batch; failed item repair and accurate unresolved issue list.
10. **Final reporting**: counts of completed actual files NOT planned entries; final paths, contact sheets, Unity screenshots, and blockers.
