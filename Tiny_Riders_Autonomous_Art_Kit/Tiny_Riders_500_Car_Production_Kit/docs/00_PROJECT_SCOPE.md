# Scope — autonomous art-only production

Active goal: generate TINY RIDERS 3D collectibles, all associated UV textures and locked packages, 3D environment art and Unity art imports. Autonomous Codex phases A0–A11 are governed by `GOAL_MODE_AUTONOMOUS_ART_ONLY.md`. The user does not want human approvals at every phase. Self-QA and automatic continuation are authorized. This phase intentionally excludes all gameplay programming, UI systems, save systems, audio, monetization, SDK, and publishing.

Required exact output counts: 10 families, 50 different base meshes, 100 meaningful physical builds, 500 data-linked finished art SKUs, 500 printed package fronts, 500 backs. Each 500 SKU also requires a visible loose-car and package art definition/prefab in Unity where Unity is available.

The reference package template is authoritative for brand and geometry and needs deterministic reuse. The old manual stop gates in `legacy/` are inactive.
