# 03 — THE LOCKED PACKAGING MASTER (mandatory)

**MOST IMPORTANT FILE FOR PACKAGING CONSISTENCY.** Use `references/original_boards/02_track_club.png` lower-left *Collectible Packaging* as the structural/layout primary reference. The other nine boards define each family's background illustration, palette and collection label—not alternate structural layouts.

## Canonical branded system
- Working company/brand: **TINY RIDERS** only. Use ONE approved 2D logo `design/brand/tiny_riders_logo.svg` and its raster export. No recreated letterforms per package or family.
- Shared original tagline: `SMALL CARS. BIG STORIES.` (or user-approved replacement). Same typographic hierarchy and logo proportions for every card.
- Family label chip/ribbon below the logo changes between `CITY CREW`, `TRACK CLUB`, etc. Same position and fixed height, text as 2D flat artwork.
- Product name and collectible number never move across families. `001/500` is the canonical numbering system; do not import arbitrary numbers from the concept boards (e.g. `#23` is a race livery number, NOT the product catalog number).
- No using famous toy brand logos, Hot Wheels branding, real automotive logos, or protected characters.

## Front-of-card production coordinate system — LOCKED
- Physical artboard: **120 mm W × 180 mm H** (W:H 2:3), cardboard thickness about 0.7 mm. Printing master canvas **1200 × 1800 px** (scale 10 px/mm); export larger from SVG when needed.
- Front UV should map an entire dedicated rectangular plane face, not an image projected over every car and blister. Back has a separate independently readable texture.
- TOP-LEFT pixel origin. All coordinates below belong to the 1200×1800 flat canvas; allow at most ±12 px on fixed elements for production tolerance. DO NOT use a new composition for each product.

| Area / element | Locked pixel region (x,y,w,h) | Rule |
|---|---|---|
| Round card silhouette | (0,0,1200,1800), ~30px corner radius | Identical across 500 |
| Hanging die-cut | centered x=600; y=45..105; width ~135px | Same physical cutout in 3D, not printed |
| Brand/logo safe zone | x=100..1080, y=135..340 | **Exactly same logo asset and position** |
| Family banner | x=100..620, y=350..430 | Fixed geometry, family flat label and color only |
| Hero print-image zone | x=90..1110, y=460..965 | Must use render of SAME approved car |
| Blister projection region | x=86..1114, y=975..1515 | Transparent 3D blister; printed layer behind it remains a simple designed background |
| Model-name footer strip | x=90..950, y=1542..1700 | Consistent type, color chips vary by family |
| SKU number badge | x=955..1138, y=1560..1700 | Exact dynamic catalog number and rarity encoding |
| Edge safe area | 55px on all sides | No important text near trim |

Actual *blister geometry* is one shared low-poly rounded cavity with a flange. Its front projection always fits the locked region and may adjust **depth only** for vehicle size; don't move it up or down per model. Large work vehicles must be scaled uniformly to fit; if impossible, explicitly request a second approved `TALL` package size family before proceeding.

## Art direction matched to reference
- Top card: bright block color, simple checkered/diagonal or family themed motifs. Brand prominent and bold, white with dark-blue outline, family-color accents. Make the logo flat 2D graphics.
- Hero zone: colorful flat scenery motif plus a posed illustration generated by rendering the **actual finalized car**, never a different hallucinated model.
- Lower zone: real physical car inside real clear plastic blister; **no printed duplicate car beneath**. Blister edge lightly catches studio light; card remains visible behind.
- Footer: bold product name, family tag, dynamic number, tasteful common/rare icon. No unreadable microcopy from AI sheet.
- Back: exact 1200×1800 artboard, mirrored-free text, same logo anchor and family bar, approved family lineup thumbnails (rendered from actual cars), simple original game icon row and descriptive text.

## Backend texture rules
1. `design/packaging/svg/` includes 10 family front/back editable 2D layout templates. These are source *guides/bases* with blank hero zones—not finished per-car print art.
2. The final high-resolution master front/back textures are composited from: approved universal logo + family backdrop + exact-car render + 2D product data + footer + optional 2D rarity foil graphic.
3. The numbers, letters, decorative checkers, racing flags, mountains, teeth/eyes and barcode-looking details are **pixels/vectors** in a texture. No letter mesh, no word curves, no floating front decal planes.
4. For game runtime, don't ship 500 full 1200×1800 uncompressed artwork pairs. Generate reduced/atlased assets and make selected inspection car use higher resolution content on demand. Full masters remain archived offline.
5. Blender image textures of card front and back need real UVs and an independently provided edge cardboard material. The plastic blister is separate true geometry, not preprinted in a card texture.

## HARD CONSISTENCY CHECKS
- Package silhouette, cutout, master brand logo, family banner y-position, printed hero/real blister division, footer position, overall hierarchy remain unchanged for ALL 500 products.
- Same unit scale, orthographic preview camera, lighting rig, card material and blister shader for all packages.
- No generation of 500 unrelated AI pack pictures. One deterministic package artwork generator from catalog and approved assets.
- A gray clay override makes every logo, word, car illustration, text, race flag and stripe vanish, while cardboard and blister remain.
- The image on the printed card must match the model inside down to livery, wheels, custom accessories and edition; provide side-by-side QA screenshot.
- Product number must match catalog exactly; race livery number is independent and may differ.
- Any reviewer-noted mismatches require revising the template once and regenerating affected cards, not hand-photoshopping each one.

## Canonical sources and consistency caveat
The generated boards are *illustrative*, not pixel-perfect source art. A single canonical family-independent packaging layout must be locked by the user from the Track Club card reference; the templates included in this kit implement a consistent measured interpretation. If the user wants a closer logo/art pose, revise and APPROVE the master template once, **before** multiplying it into 500. Don't claim screenshots can serve as exact editable packaging maps.
