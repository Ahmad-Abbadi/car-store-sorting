SceneDock – Changelog
=====================

Version 1.0.0
-------------
Initial release.

Features:
- Dockable Unity Editor window for managing scenes
- Fast scene switching with one-click loading
- Scene favorites for quick access
- Scene categories for better organization
- Search functionality for large projects
- Editor-only implementation (no runtime impact)

Supported Unity Versions:
- Unity 2021.3 LTS and newer
