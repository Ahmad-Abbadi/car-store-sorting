Read `CODEX_GOAL_PROMPT.md` and `docs/01_FULL_PRODUCTION_ARCHITECTURE.md` before editing assets. Use the immutable original 500 SKUs as the catalog identity; new sources are `catalog/masters_25.json`, `catalog/body_to_master_50.json`, `catalog/builds_100.json`, `catalog/collectibles_500_v2.json`. This v2 art-only design supersedes the older 50-master primitive modeling plan. Never claim that JSON entries or source reference concept PNGs constitute finished geometry.

Produce art autonomously without routine pause-for-approval and checkpoint batches so work can resume. But DO NOT auto-approve premium master meshes that visibly fail quality; if no lawful usable source is available, mark it blocked and process independent masters. Never make unauthorized paid downloads or purchases. Never report work running beyond actual tool/session access.

Mandatory: chunky consistent toy style, licensed original 3D geometry, all printed numbers/words/logos/stripes as UV-mapped 2D artwork (not 3D geometry), one locked packaging structure across 500 SKUs, exact car render on its own package, usable Blender and Unity asset review shots.

Do not implement gameplay, sorting systems, economy, menus, ads, SDK, or other tech beyond Blender generation and art-only Unity import/preview automation.

Use editor-driven shared meshes/prefabs, avoid 500 copies of the same body mesh. Produce actual files and evidence and log truthful counts.
