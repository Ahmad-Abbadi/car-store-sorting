# Master source quality and licensing gates

The real quality gain in this redesign comes from **25 approved high-quality base meshes**, not from a more aggressive AI prompt. Old gray primitive car result is unacceptable as a master.

## Approved source methods

1. Owned/commissioned original stylized meshes, supplied as editable source with usage rights.
2. Commercially licensed meshes permitting modification and distribution *within a game*, with provenance recorded.
3. Carefully reviewed and corrected image-to-3D or Blender procedural candidates only if they visibly pass all checks. AI-generated candidates are not automatically premium.

Do not download, rip, extract, or rehost game/car meshes without appropriate rights. Do not buy or authorize paid licensing independently unless the user has approved purchase conditions. A reference concept board is NOT mesh source.

## Quality evaluation matrix (record evidence; not fake numeric scores)

- **Shape:** premium chunky toy silhouette readable in thumbnail; intentional cabin/roof/hull relationship; not primitive blockout.
- **Geometry:** proper arch clearance, wheels correctly seated, no normal cracks or distracting sharp seams, no unsupported floating modules.
- **Style:** consistent wheel-to-body ratios, materials and bevel language across 25 masters.
- **Identity A/B:** two named variations share source but differ structurally through actual nose, cab, roof, rear deck or cargo modules, not only colors.
- **Build standard/custom:** meaningful additional geometry for custom, source of change described in catalog.
- **Printed art:** text, 2D graphics, decals, lamps and dark window areas are UV texture-driven; no extruded lettering.
- **UV:** real unwrap, no mirrored readable text, appropriate padding and no missing source files.
- **Unity material:** external texture maps correctly mapped to URP materials; alpha on blister tested.
- **Ownership:** name/author/license/local source filepath and rights recorded for every source model.

## Rendering gate

Produce *actual* 3D model screenshots: front three-quarter, side, front, top, clay, and package (when ready). Prefer identical studio camera, environment and rotation for objective comparison. A black-silhouette sheet should include all 25 masters and A/B body variants. A nominal polycount isn't a quality metric.

## Failure policy

- If mesh is not actually appealing, do NOT scale it into twenty products.
- Try specific repairs; reject and replace source if geometry cannot be fixed appropriately.
- Continue on independent approved masters to avoid blocking entire catalog.
- Record skipped SKU IDs and counts honestly; do not assign `APPROVED` statuses without real saved inspection evidence.
- If no adequate master sources can be obtained, stop short of a false 'completed' report, and give the user a shopping/commissioning list by master ID (do not purchase without permission).
